# Cybersecurity Terminology for Beginners

This document contains basic cybersecurity terms that I am learning as I prepare for my cybersecurity degree.

## 1. IP Address
An IP address is a unique numerical address assigned to a device on a network. It helps devices communicate with each other.

## 2. Firewall
A firewall is a security system that monitors and controls incoming and outgoing network traffic based on security rules.

## 3. Malware
Malware is malicious software designed to damage, disrupt, or gain unauthorized access to computers and networks.

## 4. Phishing
Phishing is a cyberattack where criminals use fake emails, messages, or websites to trick people into revealing sensitive information.

## 5. Encryption
Encryption converts readable information into coded information to protect it from unauthorized access.

## 6. Authentication
Authentication is the process of verifying someone's identity before allowing access to a system.

## 7. Network
A network is a group of computers and other devices connected so they can communicate and share information.

## 8. Operating System
An operating system is software that manages a computer's hardware and software resources. Examples include Windows, macOS, and Linux.
